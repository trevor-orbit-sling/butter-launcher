# Optional Butter bounce screen saver

**Butter bounce** moves a small Butter Launcher wordmark around a black screen. It bounces at the edges and changes between muted colours.

![Butter bounce on the TV](images/14-butter-bounce.png)

Open **Customise → Screen saver**, then select **Butter bounce** in your TV's screen saver settings and choose when it should run. If the TV does not provide that settings screen, the shortcut opens general TV settings instead.

Look for the TV's actual **Screen saver** or **Daydream** picker if one is exposed. A manufacturer's **Display → Screen** control is a separate vendor setting: Butter does not control it, and a disabled control does not explain whether the TV supports selecting Butter bounce.

This is optional. Installing Butter Launcher does not select a screen saver, enable it or change the TV's idle timing. To stop using it, choose another screen saver in your TV settings.

On supported system implementations, the first remote or touch input dismisses the screen saver. Some TVs restrict which screen savers can be selected or when they can run. If Butter bounce is unavailable or disabled, see [[Troubleshooting|troubleshooting]].
